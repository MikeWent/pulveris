Motor control

Hold a direction button or arrow key to move. Releasing it or losing the connection stops remote motion. Stop also takes remote control. Switching to physical controls can start motion if a relay contact is already closed.

Remote steering drives directly; line following and its line-loss stop apply in physical mode. A live camera is required in both modes.

Live tuning

Changes apply and are saved when you select Save. Changing resolution briefly stops the motors; motion can resume if a control is still held. The camera may select a different supported size.
