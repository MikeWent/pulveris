Motor control

Hold a direction button or arrow key to move. Releasing it or losing the connection stops remote motion. Stop also takes remote control. Switching to physical controls can start motion if an input is already high.

Remote steering drives directly; line following and its line-loss stop apply in physical mode. A live camera is required in both modes.
